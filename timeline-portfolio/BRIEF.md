# Portfolio Website — "Time Travel Through My Career"

## Concept
Horizontal timeline experience: dark premium background, editorial typography,
subtle motion, persistent top timeline + bottom year navigation, Cmd+K "Time Jump"
palette, contact experience. Sections vary in layout (not cards everywhere).

## Stack
Next.js (App Router) + TypeScript + Tailwind + Framer Motion.
Contact: server API route (Resend), rate-limited, spam-protected.

## Content architecture
All timeline data lives in `data/timeline.ts` — no invented metrics.
